# Contributing to Midwicket

First off, thank you for considering contributing to Midwicket! It is people like you that make Midwicket such a great tool for cricket analytics.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Install dependencies using Poetry: `poetry install`.
4. Run tests to ensure everything is working: `poetry run pytest`.

## How to Contribute

- **Report Bugs**: Use our Bug Report template. Please provide as much detail as possible, including code snippets and environment details.
- **Suggest Features**: Use our Feature Request template. Explain the use case and how it benefits the broader community.
- **Submit Pull Requests**: 
  - Create a new branch (`git checkout -b feature/your-feature`).
  - Make your changes. Ensure tests pass and the code is formatted using `black` and `ruff`.
  - Push to your fork and submit a Pull Request against the `main` branch.

## Code Style

We strictly follow Python PEP-8. All code must be type-hinted and pass `mypy --strict`.
