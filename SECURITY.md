# Security Policy

## Supported Versions

Currently, only the latest major release of Midwicket is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within Midwicket, please send an e-mail to our security team at security@midwicket.org. All security vulnerabilities will be promptly addressed.

Please **do not** report security vulnerabilities via public GitHub issues.

### Vulnerability Response Process

1. We will acknowledge receipt of your vulnerability report.
2. We will investigate the issue and determine its severity.
3. If confirmed, we will work on a patch in a private repository.
4. We will release the patch and publish a security advisory.
